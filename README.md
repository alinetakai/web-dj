App Web interativo de DJ que usa PoseNet (ml5.js) para transformar movimentos dos pulsos em controles de volume e velocidade da música, tudo em tempo real via webcam.

Desenvolvido para fins educacionais, com o objetico de demonstrar como a IA pode criar experiências musicais divertidas e acessíveis no navegador, aplicando conceitos de machine learning e fundamentos de programação com JavaScript.

---
## 📚 Aprendizados
- Como usar o PoseNet (ml5.js) para ler pontos do corpo em tempo real.
- Uso de PoseNet para detectar pulsos com precisão
- Manipulação de áudio com p5.sound
- Criação de interações musicais via movimento corporal
- Integração entre vídeo, IA e áudio em tempo real

## ⚙️ Funcionalidades
🎥 Leitura da webcam em tempo real

🧠 Rastreamento do pulso esquerdo e direito via PoseNet

🔊 Controle de volume com o pulso esquerdo

⚡ Controle de velocidade da música com o pulso direito

💿 Reprodução de áudio com p5.sound

🎨 Interface com ícones animados (discos girando)

🎚️ Ajustes exibidos dinamicamente na tela

## 🛠️ Stack
- JavaScript
- HTML5
- CSS3
- Bootstrap
- p5.js
- ml5.js
- PoseNet

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/alinetakai/web-dj
```

2. Abra o arquivo `index.html` em seu navegador.
